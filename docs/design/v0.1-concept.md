# v0.1 interface concept

The implementation reference for the first Vehicle Intelligence workspace is stored in `concept-dashboard.png`.

The concept establishes:

- a dark, restrained lookup header;
- an identity-first Vehicle Passport summary with permanent official link-outs;
- open-list Mechanical DNA rather than opaque summary cards;
- visible inferred/unknown states and an evidence inspection surface;
- a competing-hypothesis investigation next to discriminating tests;
- no unsupported “failed turbo” conclusion.

All interactive text and controls are implemented as native HTML rather than embedded image content.
